# New game

Follow `docs/new-game.md` in order. Each step names the gate that proves it; don't start the
next step on a red gate.

Before step 1, read README.md (the five properties) and docs/layout.md (kit vs game, the seam).
The rule: keep kit files, replace game files, and never make kit code name game content.
